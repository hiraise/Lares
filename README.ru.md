# FamilyHub

*Рабочее название.* [English version](README.md)

Личное пространство вашей семьи на вашем собственном сервере. Общие задачи и домашние дела, списки покупок,
семейный календарь с днями рождения родственников, карта, где видно, кто где, и семейный бюджет — всё связано тегами.

> **Статус: идёт планирование.** Устанавливать пока нечего. Прогресс — в [docs/STATUS.md](docs/STATUS.md).

## Что будет

- **Задачи** — разовые и регулярные дела, с назначением и очерёдностью между членами семьи.
- **Списки покупок** — общие, работают в магазине без интернета.
- **Календарь** — события и дни рождения, с указанием, кого касается, и напоминаниями.
- **Карта** — кто где находится, места вроде «Дом» и «Школа» с уведомлениями о приходе; позже — GPS-маячки и детские часы.
- **Бюджет** — распределение доходов по категориям по вашим правилам, перерасход, займы между категориями, долги.
- **Теги** — поставьте тег «Машина» и увидите её задачи, события и расходы в одном месте.

## Принципы

- **Свой сервер.** Данные остаются у вас. Без облака, без слежки, без рекламы.
- **Бесплатно навсегда.** Открытый код под AGPL-3.0, без платных подписок.
- **Без Google.** Работает на любом Android-телефоне, с сервисами Google или без них.
- **Работает без сети.** Изменения синхронизируются, когда связь появится.

## Платформы

Сервер: Docker Compose на любом Linux VPS или домашнем сервере. Приложение: сначала Android, затем веб, iOS и десктоп.
