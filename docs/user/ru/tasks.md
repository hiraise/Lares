# Задачи

Общие дела и обязанности семьи: кто, что и когда делает. Всё работает без интернета; изменения дойдут до других
телефонов, как только появится связь.

## Где искать задачи

- **Сегодня** (первая вкладка) показывает ваши просроченные задачи, задачи на сегодня и то, что вы уже сделали сегодня.
  Задачу можно отметить прямо здесь. **Все** открывает вкладку «Задачи».
- **Задачи** (вторая вкладка) показывает задачи по разделам: «Просрочено», «Сегодня», «Скоро», «Без срока».
  - **Мои** — задачи, назначенные вам, и задачи для всех («Кто угодно»).
  - **Все** — задачи всей семьи.
  - **Поручено мной** — задачи, которые вы создали для других.
  - **Метка** оставляет в списке задачи с одной меткой. Поиск и фильтры — кнопки вверху.
- На **странице метки** собраны все открытые задачи с этой меткой. Откройте её в «Ещё» › «Метки» или нажмите на
  метку на странице задачи.

После отметки на несколько секунд появляется «Выполнено · Отменить». Позже можно открыть задачу и нажать
**Не выполнено**.

## Создать задачу

Нажмите **Добавить** на экране «Сегодня» или **Задача** на вкладке «Задачи». Обязательно только название:

- **Дата** и **Время**: задача без даты попадает в «Без срока». Задачу без времени нужно сделать до конца дня.
- **Повтор** превращает задачу в регулярную (см. ниже).
- **Исполнители**: один или несколько членов семьи или **Кто угодно** («кто первый сделает»). Новая задача с экрана
  «Сегодня» или из «Мои» назначается вам.
- **Метки**, например «Дети» или «Машина». Новую метку можно создать прямо здесь.
- **Напоминание**: в срок или за несколько минут, часов или дней. Задача без времени напоминает в 9:00. Если
  уведомления Lares на телефоне выключены, приложение предложит их разрешить.
- **Сообщить мне, когда выполнят**: придёт уведомление, когда вашу задачу выполнит кто-то другой.
- **Чек-лист**: шаги внутри задачи, например пропылесосить, протереть пыль, помыть пол.

Если исполнителей несколько, достаточно одной отметки: задача выполнена для всех.

## Регулярные задачи

У регулярной задачи видно только **текущее** повторение. Когда его выполняют или пропускают, появляется следующее.
Пропущенные повторения не копятся: просроченным бывает не больше одного, и оно исчезает, когда наступает следующая
дата.

Бывает два вида:

- **По расписанию**: каждый день, по выбранным дням недели, каждый месяц в одно и то же число, каждый год. Пример:
  «Вынести мусор» по понедельникам и четвергам в 20:00. Если в понедельник никто не вынес, задача просрочена до
  четверга, а в четверг её место занимает четверговое повторение.
- **После выполнения**: следующая дата считается от дня, когда задачу на самом деле сделали. Пример: «Поменять фильтр
  для воды» через 3 месяца после выполнения. Сделали на две недели позже — следующий срок через 3 месяца от этого дня.

На странице регулярной задачи есть история: кто и когда её делал. Чтобы пропустить одно повторение, нажмите
**Пропустить**. При удалении выберите **Только это повторение** или **Всю серию**. Чтобы остановить повтор,
удалите серию.

Чек-лист регулярной задачи для каждого повторения начинается заново.

## Напоминания и уведомления

- **Напоминания** настраиваются на самом телефоне и срабатывают вовремя даже без интернета. Они приходят
  исполнителям, а для задач «Кто угодно» — всем, кто видит задачи.
- **Уведомления** присылает семейный сервер:
  - «Мне назначили задачу»;
  - «Задача выполнена», если вы просили сообщить;
  - «Задача просрочена» — создателю задачи. Для задачи без времени оно приходит в 9:00 следующего дня.
- Для мгновенных уведомлений на телефоне нужно приложение **ntfy**, см. [Мгновенные уведомления](instant-notifications.md).
  Без ntfy приложение проверяет новости примерно раз в 15 минут.
- Нажмите на уведомление или напоминание, чтобы открыть задачу. Если задачу уже удалили, Lares откроет список задач и
  сообщит об этом.
- Любой вид можно выключить: **Ещё › Настройки › Уведомления › О чём уведомлять**: «Мне назначили задачу», «Задача
  выполнена», «Задача просрочена», «Напоминания о задачах».

## Кто что может

Это решает администратор семьи с помощью групп («Ещё» › «Семья»). По умолчанию:

| | Взрослые | Дети |
| --- | --- | --- |
| Видеть все задачи семьи | да | да |
| Создавать задачи | да | да |
| Отмечать свои задачи и задачи «Кто угодно» | да | да |
| Менять и удалять чужие задачи | да | нет |

Создатель задачи всегда может её изменить и отметить. Кто не имеет доступа к задачам, не видит вкладку «Задачи» и не
получает данные задач.
