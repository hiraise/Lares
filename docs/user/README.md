# User manuals

Manuals for people who install and use FamilyHub, in English (`en/`) and Russian (`ru/`).
Written as features ship; none exist yet.

Planned:

- Installing the server on a VPS (domain, Docker Compose, HTTPS)
- Backup and restore
- First setup: household, inviting members, child accounts
- Installing the Android app and connecting to the server
- Instant notifications with ntfy
- Location sharing and battery settings on different phone brands
- One guide per module: tasks, shopping lists, calendar, map, budget, tags
