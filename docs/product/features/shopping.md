# Shopping lists (SHP)

## Summary

Shared shopping lists that work in a store with no network.

## Requirements (outline)

- **SHP-001** `MVP` `todo` — Several lists per household (e.g. "Groceries", "Pharmacy", "Hardware store").
- **SHP-002** `MVP` `todo` — Item: name, optional quantity and unit, optional note, tags.
- **SHP-003** `MVP` `todo` — Quick add: one line per item; suggestions from previously bought items.
- **SHP-004** `MVP` `todo` — Check off items offline; checked items move to the bottom; "clear checked".
- **SHP-005** `MVP` `todo` — Two people shopping at once see each other's check-offs within seconds when online.
- **SHP-006** `later` `todo` — Group items by store section; remember order per store.
- **SHP-007** `later` `todo` — Turn a finished trip into a budget expense (after M5).
