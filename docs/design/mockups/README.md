# Mockups

Static screen mockups (390 × 844, phone) made with the customer on 2026-10-23. They illustrate
[visual-style.md](../visual-style.md); where they disagree, visual-style.md wins.

The files are HTML with inline styles (a design-canvas format); read them for exact sizes, colors and copy.
They need the canvas runtime to render, so open the canvas link from the customer if you need to see them.

| File | Screen | Notes |
| --- | --- | --- |
| `Login.dc.html` | Connect to server | App icon, server URL, QR invite |
| `Main.dc.html` | Today (light) | Hero = active shopping list; tasks, upcoming, family now, budget |
| `TodayDark.dc.html` | Today (dark) | Offline sync chip with pending count |
| `More.dc.html` | More | Profile, section tiles, settings list |
| `Family.dc.html` | Family → Members | Group chips, pending invite, "Invite" FAB |
| `Tasks.dc.html` | Tasks | Filter chips, groups by due date, recurrence, tags, assignees |
| `Shopping.dc.html` | Shopping list in a store | Offline banner, quick add, suggestions, bought items collapsed |
| `Calendar.dc.html` | Calendar month | Event dots in personal colors, day agenda |
| `Map.dc.html` | Map | Places, avatar pins, family sheet, "sharing" notice with pause |
| `Budget.dc.html` | Budget | Unallocated hero, categories with deficit and loan, debt payment |

Names, places and amounts are examples. Real content comes from module specs.
